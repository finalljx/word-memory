# 词卡 · 五年级英语单词记忆

一个「以记住为目的」的极简背词工具：翻面自测、记 / 没记住、间隔复习、SQLite 记录进度、选择题与听写两种自测。

不追求游戏化——没有积分、没有徽章、没有排行榜。只有一个目标：**合上书能把词掏出来。**

## 文档

- [AGENTS.md](AGENTS.md) — 给后续接手的人 / agent 看的项目说明：目录、数据模型、核心机制、接口、约定、已知坑
- [docs/llm.md](docs/llm.md) — LLM 模块详解：配置、提示词、路由契约、错误码、无 key 测试、加新能力的步骤

## 启动（macOS，推荐）

**不用命令行，双击就行：**

| 文件 | 作用 |
|---|---|
| `启动词卡.command` | 双击启动，自动开浏览器；关掉终端窗口即停止 |
| `制作桌面图标.command` | 在桌面生成「词卡.app」，以后双击图标即可，**不弹终端** |
| `停止词卡.command` | 停止后台运行的词卡 |

第一次打开 `.command` 如果提示「无法打开，因为无法验证开发者」：右键文件 → 打开 → 再点「打开」即可。

桌面图标同理，第一次右键 → 打开。

> 桌面图标里记的是当前文件夹的绝对路径，**如果以后移动了 `word-memory` 文件夹，重新双击一次 `制作桌面图标.command`** 即可。后台运行日志在 `logs/server.log`。

要求 Node ≥ 22.5（用到内置 `node:sqlite`，**无需 npm install**）。没装或版本太旧时，脚本会弹窗提示并给出下载地址。

## 启动（命令行）

```bash
cd word-memory
node server.js          # 或 npm start
```

打开 <http://127.0.0.1:4610>。

改端口：`PORT=5000 node server.js`。

## 页面

| 页面 | 做什么 |
|---|---|
| **学习** | 卡片正面只有单词和音标。先回想，点一下翻面，看英文解释、音节、词块、主钩、词族、例句。然后点「记住了」或「没记住」。「练什么」由顶部模式栏决定 |
| **自测** | 三种题型：选择题、听写（听发音写单词，自动播报，默认显示英文解释）、例句填空（把单词填回句子）。考什么同样由顶部模式栏决定；一轮内每个词只出现一次，全部过完给出成绩单，可「只测错的」「再来一轮」 |
| **进度** | 已掌握 / 学习中 / 待开始 / 今日正确率、六个记忆箱的分布、逐词状态、词库的情节故事（可点「AI 串联」用当前词库的单词重新生成） |
| **管理** | 快速录入、单词列表（新增 / 编辑 / 重置 / 删除）、错词本（全词库共享）、新建词库、JSON 导入导出 |
| **词库**（`#decks`） | 所有词库一览：单词数、掌握数、待复习、错词数，以及每个词库包含的单词；支持按**词库名或单词**搜索、分页（3 个/页），以及进入学习 / 管理 / 重命名 / 删除 |

键盘：`空格` 翻面、`←` 没记住、`→` 记住了、`S` 发音、选择题 `1–4` 选项、`回车` 下一题。

## 模式栏：全部 / 错题

学习和自测共用一个模式：

- **全部模式**：学习按间隔复习队列，自测考当前词库的全部单词
- **错题模式**：学习只过错词，自测只考错词；可以再按**词库**和**时间**（今天 / 近 3 天 / 近 7 天）筛选，和错词本共用同一套条件

模式记在浏览器里，下次打开还是上次选的；切词库不会丢。

## 全对闯关

点学习页的「全对闯关」：这一组所有词过一遍，错的进下一轮，**直到某一轮一个都没错**才通关。

- 每轮结束显示「还差 N 个」，点「进入第 N 轮」只练这些
- 全部对了给「全部背对了」，显示用了几轮
- 「错词 N 个 · 只练这些」直接把错词本里的词拉进来闯关

## 词库

顶部只显示**最近使用的 3 个**词库（`last_opened_at` 记录最近打开时间），加上一个「全部 N 个 →」入口。

`#decks` 页面列出所有词库，每个词库下面平铺它的单词（错词标红），并显示该词库的掌握 / 待复习 / 错词数量；可以直接学习、进入管理、重命名或删除（删除会连带删除单词和复习记录）。

## 迁移到另一台电脑

1. 新电脑装 **Node.js ≥ 22.5**（`node -v` 确认，需要内置 `node:sqlite`）
2. 把整个 `word-memory/` 文件夹拷过去（`data/` 和 `config.json` 可以不带）
3. 旧电脑：管理页 → **导出数据（.db）**，得到一个 `word-memory-日期.db`
4. 新电脑：`node server.js`，打开管理页 → **导入数据**，选这个文件
5. 配 key：复制 `config.example.json` 为 `config.json` 填 key，或设 `DEEPSEEK_API_KEY`
6. 打开 <http://127.0.0.1:4610>

说明：

- 导出文件包含 `decks / words / progress / reviews` 全部数据，**不含 API key**
- 导入会覆盖现有数据，覆盖前会自动备份成 `data/words.db.bak-时间戳`
- 也可以直接拷贝 `data/words.db` 过去，效果和导入一样
- 顶层词库选择存在浏览器 `localStorage`，换机器会回到第一个词库

## 发音

点卡片上的 🔊（或按 `S`）就出声。发音走词典的**真人录音**，不再用浏览器自带的语音合成，清楚得多。

- 第一次点需要联网拉一段音频，之后存在 `data/audio/`，断网也能放、再点几乎零延迟
- 学习卡会预加载当前词和下一个词，翻卡后点立刻响
- 自测「听写」页有 🐢 慢速：按 0.62 倍速放，音调不变，适合跟读
- 默认英音。想要美音，浏览器控制台执行一次 `localStorage.setItem('wm.accent','us')`，刷新即可
- 拉不到录音（断网、服务没起来）时自动退回系统朗读，不会没声音

## 打印

词库页每个词库有「打印」，管理页错词本有「打印错题」。点开先看 A4 预览，再点右上角「打印」调起浏览器打印（可选另存为 PDF）。

- 版式：A4、两栏，18 个词能排进一页
- 可勾选显示：英文解释 / 主钩 / 例句 / 中文（关掉中文就是纯英文版）
- 错题打印每条形带「错 N 次 · 来源词库」
- 错题预览页顶部有「AI 串联」：用这批错词生成一段小故事，排在词表前面一起打印（只在预览里，不落库）
- 直接访问 `#print/deck/<词库id>` 或 `#print/wrong` 也能打开预览

## 管理

- **快速录入**：一行一个。
  - **只写英文**：`fresh`、`sweet` —— AI 自动补中文和其余全部字段（没配 key 时会提示需要配置）
  - **带中文**：`fresh | 新鲜的 | tasting not old`，分隔符支持 `|` `｜` Tab 和逗号，`- ` 列表符号和 `#` 注释行自动忽略
  - 同一个词库里已存在的词会被**更新**而不是跳过；只写英文重新粘贴时，会清掉旧中文让 AI 重新生成
- **单词列表**：支持按单词或中文搜索、分页（10 个/页）
- **＋ 新增单词**：打开完整表单（音标、音节、词块、主钩、备钩、词族、例句、提取题、近反义）。只填英文也行——点「AI 补齐」会把结果填进表单，可以先改再保存；直接保存也会在后台补齐
- **错词本**：**所有词库共享**。支持按**词库**和**时间**（今天 / 近 3 天 / 近 7 天）筛选，按错误次数排序并标注所属词库；背对后自动移出。「只练这些错词」和「打印错题」都跟着当前筛选走
- **重置**：把单个词的复习进度清零，回到第 0 箱
- **导入 / 导出**：整库 JSON，方便备份或换设备

## AI 补齐（可选）

在「管理」页录词时，可以调用 DeepSeek 自动补齐缺失字段：音标、词性、英文解释、音节、词块、主钩、备钩、词族、例句、提取题、近反义。**只补空的，不覆盖你已经写过的内容。**

配置二选一：

**方式一：环境变量**

```bash
export DEEPSEEK_API_KEY=sk-...
node server.js
```

**方式二：配置文件**

```bash
cp config.example.json config.json
# 编辑 config.json，填入 deepseek.apiKey
```

`config.json` 已在 `.gitignore` 里，不会被提交。

可选变量：`DEEPSEEK_BASE_URL`（默认 `https://api.deepseek.com`）、`DEEPSEEK_MODEL`（默认 `deepseek-chat`）、`DEEPSEEK_TIMEOUT_MS`。

配置改完**刷新页面即可生效**，不用重启（状态每次请求重新读取）。

用法：

- 管理页顶部会显示「已启用 · deepseek-chat」或「未配置」
- 点「测试连接」验证 key（只调 `/models`，不花 token）
- 批量粘贴后自动补齐：配置了 key 就会直接跑，不需要勾选；并发 3 个，顶部显示 `AI 补齐中 2/5…`
- 也可以点每行的「AI」按钮单独补一个

提示词按本项目的单词卡规范写死了：英文解释 ≤10 词、主钩必须解释「为什么挂得上」、谐音必须注明「只借声音」、例句不超过 12 词。

## 复习算法

莱特纳记忆箱（Leitner box），箱号对应下次复习间隔：

| 箱 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 间隔 | 立即 | 1 天 | 2 天 | 4 天 | 7 天 | 15 天 |

- 点「记住了」：进一箱，按新箱号排下次复习
- 点「没记住」：退回第 0 箱，**1 分钟后**可以再练，同时 `wrong_count + 1`（进错词本）
- **难词**：错 2 次以上的词，记忆箱封顶在第 3 箱（4 天），不会因为连续答对而被排到 15 天后；学习卡上会标「难词」
- 选择题 / 听写 / 填空**答错立刻进错词本**，不用等一轮做完，中途退出也不会丢（答题时就落库）

## 数据

SQLite 文件：`data/words.db`（首次启动自动建表并灌入种子词）。

四张表：

- `decks` — 词库（含情节故事、场景描述）
- `words` — 单词卡的全部字段
- `progress` — 每个词的箱号、下次到期时间、复习次数、累计错误次数（`wrong_count`）
- `reviews` — 每一次复习的流水（时间、对错、模式、耗时）

想加词：编辑 `seed.js`，往某个 deck 的 `words` 里加一条，然后**删掉 `data/words.db` 重启**（种子只在空库时写入）。字段与 skill 里的单词卡一一对应：

```js
{
  word: 'mountain', ipa: '/ˈmaʊntən/', pos: 'n.', cn: '山；山脉',
  enDef: 'a very high hill',
  syllables: 'moun · tain（2 拍，重音在前）',
  chunks: ['climb a mountain', 'a high mountain'],
  hook: '【图像·对比】…',
  altHook: '【谐音】…',
  family: 'mountain → mountains；对比 hill',
  example: 'There is a high mountain behind the village.',
  extracts: ['看「山」写 mountain'],
  synonyms: '', antonyms: 'hill',
}
```

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/state?deck=taste` | 词库列表 + 当前词库全部词 + 统计 |
| GET | `/api/queue?deck=taste&limit=60` | 到期队列（含统计） |
| POST | `/api/review` | `{wordId, remembered, mode, elapsedMs}` |
| GET | `/api/quiz?deck=taste&type=choice\|spell` | 出一道题 |
| POST | `/api/quiz/answer` | `{wordId, type, answer}` |
| GET | `/api/stats?deck=taste` | 统计 |
| POST | `/api/reset` | `{deck}` 或 `{}` 全部重置 |
| GET | `/api/overview` | 所有词库 + 各自单词 + 统计 |
| GET | `/api/audio?w=word&accent=uk\|us` | 单词发音（mp3，磁盘缓存） |
| GET | `/api/wrong` | 错词列表（不带 deck 即全部词库） |
| POST | `/api/wrong/clear` | `{deck}` 清除错误标记 |
| POST | `/api/words` | 新增单词 |
| PUT | `/api/words/:id` | 编辑单词 |
| DELETE | `/api/words/:id` | 删除单词 |
| POST | `/api/words/:id/reset` | 重置单个词的进度 |
| POST | `/api/words/import` | `{deck, text}` 或 `{deck, words}` 批量导入 |
| POST | `/api/decks` | `{title}` 新建词库 |
| POST | `/api/decks/:id/story` | 用 AI 为词库生成情节故事 |
| GET | `/api/backup/export` | 导出 .db 备份 |
| POST | `/api/backup/import` | 上传 .db 覆盖导入 |
| PATCH | `/api/decks/:id` | `{title}` 重命名 |
| DELETE | `/api/decks/:id` | 删除词库（连带单词与记录） |

## 设计取舍

- **先回想，再翻面**：卡片正面不显示中文，逼大脑先提取一次；翻面后自己判断「记住没记住」，这是提取练习，不是浏览。
- **不做积分**：积分会把注意力从「这个词我能不能说出来」转移到「我得了多少分」。
- **只做 13 个词**：一个词库 5–8 个词，符合工作记忆的容量；一次给 30 个，每个词分到的提取次数反而不够。
- **没记住就 1 分钟后回来**：遗忘的词立刻重练，比等到明天有效。
